ELK Lab Kunde · Elastic

Detection rules ligger for sig

Hver fil er et objekt, eksporteret af SOROC (SD as Code). Filen opdateres automatisk, når objektet oprettes, ændres eller slettes, i SOROC eller direkte i portalen. Slettede objekter flyttes til `_deleted/` i denne mappe, så de kan gendannes.
